# hello-github

这是 `jianghaoran-2026` 的第一个 GitHub 仓库，用来跑通「创建仓库 → 推送首个提交」的完整流程。

仓库地址：https://github.com/jianghaoran-2026/hello-github

## 快速开始

需要 Python 3.8 或更高版本，无需安装任何依赖：

```bash
python hello.py
```

预期输出：

```text
Hello, world!
Hello, GitHub!
```

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `README.md` | 本说明文档 |
| `hello.py` | 一个可运行的最小示例，含 `greet()` 函数 |
| `.gitignore` | 忽略 Python、Node、编辑器和系统产生的临时文件 |

## 下一步可以做什么

- 修改 `hello.py`，加入自己的逻辑，再提交一次改动
- 加一个 `LICENSE` 和 `CONTRIBUTING.md`
- 用 GitHub Actions 加上自动测试
- 给仓库写一个项目主页（GitHub Pages）
